# 📦 Stockerty

### Optimiza los flujos logísticos

Solución tecnológica diseñada para la gestión logística, trazabilidad de los pedidos, entrada y salida de mercancía, y gestión del almacenamiento.

---

## 🛠️ Stack tecnológico

Este proyecto se desarrolla utilizando las siguientes tecnologías:

* **Backend** - Java v21.0.7
* **Base de Datos** - MySQL v8.0.46
* **Frontend** - Java Swing (Posible implementación)
